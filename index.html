Animation Studio

Animation Studio is the private production tool behind the YouTube channel Living Mechanisms, which explains animals’ abilities with animated diagrams.

It runs on its owner’s own computer. With the owner’s permission, it uses YouTube API Services to upload the episodes he approves, scheduled for their publish times with their thumbnails and captions, and to read the channel’s analytics so he can see how each episode performs.

It has one user, the channel’s owner. There is nothing to sign up for, and it does not access anyone else’s account.
